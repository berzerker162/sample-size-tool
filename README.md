# A/B Sample Size Calculator

An interactive sample size calculator for two-proportion A/B tests. Move a slider, see what changes.

**Live:** https://berzerker162.github.io/sample-size-tool/

Features: relative or absolute MDE, one/two-sided tests, unequal allocation, multiple variants with Bonferroni correction, test duration estimate, effect-size and power-curve charts, sample-size table, shareable URLs, and dark mode.

Single static `index.html` — no build step.
